# ⚡ Fog / Edge / Cloud Data Partitioning Simulator

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)

A powerful, interactive Python desktop application built with `Tkinter` that simulates data packet routing across a 3-tier IoT architecture (**Edge**, **Fog**, and **Cloud**). 

This tool is designed to visualize how data generated by various IoT devices is partitioned and processed based on size, priority, and data type to optimize network latency and bandwidth.

---

## ✨ Features

- **🌩️ 3-Tier Architecture Simulation:** Visualizes data flowing from edge devices to the **Edge** (local), **Fog** (regional), or **Cloud** (global) processing layers.
- **🎨 Real-time Animated Data Flow:** Beautiful canvas animations showing data packets (color-coded) traveling from devices to their respective processing nodes.
- **📱 Dynamic Edge Devices:** Simulate different devices like IoT Sensors, Cameras, and Industrial Sensors, each generating realistic data types (temperature, video streams, alerts, etc.).
- **📊 Live Analytics Dashboard:** 
  - **Throughput Graph:** Real-time line chart tracking packets processed per second.
  - **Latency Chart:** Bar chart comparing average processing times across layers.
  - **Distribution Chart:** Percentage distribution showing where most data is being processed.
  - **Per-Device Stats:** Detailed breakdown of how much data each specific device is sending to which layer.
- **🎛️ Interactive Controls:** Add/remove devices on the fly, adjust simulation speed via a slider, and easily pause/resume using keyboard shortcuts (`Space` to Play/Pause, `Esc` to Stop).
- **🔒 Thread-Safe Design:** Engineered with Python's `queue` and `threading` modules to ensure smooth, crash-free UI updates during high-speed simulations.
- **📱 Responsive UI:** The dashboard automatically adapts to your screen size for a consistent experience across different monitors.

---

## 🏗️ Architecture Rules (How Data is Partitioned)

1. **🟢 Edge Layer (Low Latency / Local):**
   - Handles high-priority, time-sensitive packets (e.g., Priority >= 4).
   - Processes very small data packets (< 10 KB).
   - Deals with critical alerts and motion detection data instantly.
   
2. **🔵 Fog Layer (Aggregation / Regional):**
   - Handles medium-sized data and low-priority background telemetry.
   - Ideal for data that benefits from batching/aggregation (e.g., standard temperature readings, telemetry).
   
3. **🟣 Cloud Layer (Heavy Compute / Global):**
   - Handles massive data payloads (e.g., > 500 KB).
   - Processes heavy tasks like raw video streams or complex analytics that require high computational capacity, despite the higher network latency.

## 🚀 Installation & Usage

### Prerequisites
- Python 3.8 or higher installed on your system.
- No external libraries are required! This project uses purely built-in Python modules (`tkinter`, `threading`, `queue`, `datetime`, etc.).

### Run the Simulator

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/fog-edge-simulator.git
   cd fog-edge-simulator
   ```

2. Run the application:
   ```bash
   python simulator.py
   ```

### ⌨️ Keyboard Shortcuts
- `Spacebar`: Toggle Simulation (Play / Pause)
- `Escape (ESC)`: Stop Simulation
